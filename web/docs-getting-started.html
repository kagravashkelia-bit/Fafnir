Getting started

Download, extract and connect Fafnir to a UCI chess GUI, verify the engine identity and run the first search.

Fafnir 2.0Updated 2 November 2026Reference

This guide takes you from a downloaded archive to a working engine inside a chess GUI. It assumes no prior UCI experience and no compiler. If you want to build Fafnir yourself, read the build guide instead.

i
What you needA 64-bit Windows or Linux machine, a chess GUI that speaks UCI, and the Fafnir archive that matches your CPU. The neural network is already inside the binary.

1. Choose the right build

The archives differ only in the instruction set compiled into the engine. A build compiled for AVX2 will not start on a CPU without AVX2; the safe x86-64 build runs on any x86-64 machine.

BuildRequiresRecommended when
x86-64SSE2You do not know the CPU, or you run a VM
sse4.2SSE4.2 + POPCNTThe CPU is from 2009 or later
avx2AVX2 + BMI2 + POPCNTThe CPU is Haswell (2013) / Excavator (2015) or later

On Windows, System Information shows the processor model. On Linux, lscpu lists the flags. If avx2 appears, the AVX2 archive is safe. If you are unsure, start with the safe build; you can always switch later.

2. Extract the archive

Unzip the Windows archive anywhere you can write, for example C:\Engines\Fafnir. Do not run the engine from inside the zip preview. On Linux, extract the tarball and keep the binary in a stable directory.

Linux extractbash
tar -xzf Fafnir-x86-64-avx2-linux-x64.tar.gz
chmod +x Fafnir
./Fafnir
✓
No sidecar filesThe binary is self-contained with respect to the network. Do not download or configure a separate .nnue file for the published archives.

3. Add the engine to a GUI

Any UCI-compatible GUI works. The exact menu names differ, but the flow is the same: add a new engine, point it at the binary, and let the GUI perform the UCI handshake. Common choices are Arena, Cute Chess, En Croissant and BanksiaGUI.

  1. Open the engine manager

    Look for “Manage engines”, “Install engine” or a similar entry in the GUI settings.

  2. Select the Fafnir binary

    Choose Fafnir.exe on Windows, or the extracted Fafnir binary on Linux. Do not select a source file or the archive.

  3. Choose the UCI protocol

    If the GUI asks, select UCI (not WinBoard or a generic protocol). Fafnir does not implement CECP.

  4. Confirm the identity

    The GUI should report Fafnir 2 and list five options. If it reports another name, you selected a different binary.

If the GUI offers a hash or thread setting, leave the defaults for the first run: 16 MB and one thread. You can raise Hash later without restarting the engine.

4. Run the first UCI session

You can verify the engine without a GUI. Start it in a terminal and type the handshake manually. The engine reads one command per line and writes its replies to standard output.

Minimal sessiontext
$ ./Fafnir
uci
id name Fafnir 2
id author Anthony
option name Hash type spin default 16 min 1 max 1024
option name Threads type spin default 1 min 1 max 128
option name MultiPV type spin default 1 min 1 max 256
option name Move Overhead type spin default 50 min 0 max 5000
option name Aggressivity type spin default 0 min 0 max 100
uciok
isready
readyok
position startpos
go depth 12
info depth 12 seldepth 20 score cp 31 nodes 48210 nps 402000 time 120 pv e2e4 e7e5 g1f3 b8c6
bestmove e2e4 ponder e7e5
quit
i
Reading the handshakeThe id and option lines are printed in response to uci. uciok closes the handshake. A GUI that never receives uciok will show the engine as unavailable.

5. Verify the build

Three checks catch most installation problems:

  • The engine prints id name Fafnir 2 and exactly five options.
  • isready produces readyok.
  • A short search produces info lines and a bestmove.

If the process exits immediately on Windows, you probably selected an AVX2 archive on a CPU without AVX2. If it exits on Linux with Illegal instruction, the same applies. Switch to a lower ISA build.
