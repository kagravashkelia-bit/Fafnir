History

Changelog

Every notable change, in the order it happened. The project uses descriptive commit messages rather than semantic presets, and earlier tags are kept as historical markers.

Filter
2.01 November 2026Current

The public history was consolidated into a single descriptive snapshot. Earlier development revisions remain reachable through the fafnir2 and 1.3 tags; the older releases they once backed were removed.

Added

  • Native multi-architecture build system in the root Makefile — safe x86-64, ssse3, sse4.2, avx2, avx512 and native — with per-architecture object directories and bin/Fafnir-<arch> outputs.
  • build-native.yml: Linux and Windows builds for x86-64, SSE4.2 and AVX2 with a UCI smoke test and packaged artifacts.
  • GPL v3 LICENSE and third_party/VENDORED.md, documenting ChessLib (MIT), the Stockfish SFNNv17 snapshot (GPLv3), the NNUE network and incbin (Unlicense).
  • A full documentation site with protocol, build, NNUE, WASM, testing and architecture references.

Changed

  • The UCI interface declares only implemented options (Hash, Threads, MultiPV, Move Overhead, Aggressivity). Unrecognised options answer info string unknown UCI option.
  • Project renamed FlashBit → Fafnir (repository, website, identity strings).
  • The NNUE network is committed as a plain git blob again (no Git LFS), so clones and CI embed the real network without an LFS smudge step.
  • Makefile.wasm and the CI build are portable across cmd.exe, MSYS2 sh, Linux and macOS shells (idempotent mkdir, no 2>nul).

Removed

  • The unbuildable JNI bridge (src/bridges/java_api.{h,cpp}, integrations/java-jni/). Its legacy probe API does not compile against the vendored sfdev snapshot.
  • Long-dead Stockfish probe/ code is no longer referenced by any build. CI no longer mutates the vendored incbin.h; network embedding is disabled for WASM via NNUE_EMBEDDING_OFF.

Fixed

  • build-wasm.yml compiles again after the 31 October reorganisation broke it by pulling in JNI and legacy probe sources.
  • Windows mkdir no longer aborts when directories already exist during native builds.
EarlierBefore 1 November 2026Historical

Revisions before the consolidation are tagged fafnir2 (engine snapshot) and 1.3. Their published releases were removed, so these tags are historical markers rather than supported downloads.

Context

  • FlashBit was the previous project name.
  • The engine moved to the Stockfish development SFNNv17 evaluation architecture with a single-output network.
  • The public Git history was reduced to keep the repository auditable and the network as a normal blob.
