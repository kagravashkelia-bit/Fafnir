Direction

Roadmap

No dates, no promises disguised as plans. This page records what has shipped, what is actively being prepared, and what is only being explored. Anything not backed by working code stays out of the engine and out of the UCI option list.

Shipped

5 items
2.0

Multi-architecture native builds

Safe x86-64 default plus SSSE3, SSE4.2, AVX2, AVX-512 and native targets.

2.0

SFNNv17 network embedded

98,668,604-byte network loaded with incbin; no external file required.

2.0

Honest UCI surface

Five implemented options; unknown options rejected with an info string.

2.0

WASM CI repaired

Emscripten build produces an artifact again, with embedding disabled.

2.0

Documentation site

Protocol, build, NNUE, testing, architecture and troubleshooting references.

Next

3 items
In preparation

Public WASM edition

Wrap the five C functions in a browser build with a small board UI. The API is documented before the UI exists.

Planned

Syzygy tablebase support

Implement, test and only then declare the UCI options. No placeholder options in the meantime.

Planned

More regression coverage

Keep the 100-position EPD suite green and add targeted positions for every search change.

Exploring

3 items
Unscheduled

Evaluation tuning

Measure whether the current network and search parameters are the right trade-off on the project's own test set.

Unscheduled

Alternative compilers in CI

Clang and MSVC are accepted through the Makefile but are not validated by CI today.

Unscheduled

Opening book support

Only if it can be implemented without turning the engine into a book viewer. The GUI remains the better place for books.

How this works

Three rules for the roadmap.

  • Ship before declaring. A UCI option appears only when it does something.
  • Measure before claiming. Performance changes need a reproducible run, not a feeling.
  • Document the removal. Dropped interfaces are recorded in the changelog, not deleted silently.
Not on the roadmap
Not plannedWhy
Closed-source binariesThe engine links GPLv3 code.
Telemetry or update checksA local engine should stay local.
Fake UCI optionsDeclaring unimplemented features breaks GUIs.
A built-in GUIUse the GUI you already trust.
Elo marketingSpeed and test results are published; ratings are not invented.
