NNUE evaluation

Fafnir's SFNNv17 network: feature sets, embedding with incbin, quantization, hash verification, provenance and replacement rules.

Fafnir 2.0Updated 2 November 2026Reference

Fafnir uses the Stockfish development SFNNv17 evaluation architecture with a single-output network and no PSQT. The network is loaded at link time with incbin; the native engine needs no external evaluation file.

Feature sets

The probe compiles only the subset of the vendored evaluator that the SFNNv17 network requires. Three feature families are active:

  • half_ka_v2_hm — half-king, attacker and piece features with horizontal mirroring.
  • full_threats — threats against pieces and pawns, including discovered and overloaded cases.
  • pp_3wide — a three-wide pawn-pattern feature set.

Other Stockfish feature sets present in the vendored tree are not compiled into Fafnir. Keeping the compiled surface small reduces build time and makes the binary easier to audit.

Embedding

The network sits at assets/nnue/nn-252f33942263.nnue and is included by the native build with incbin. The file is a normal Git blob (not an LFS pointer), so a clone contains the actual bytes and CI embeds the real network without a smudge step.

Embedding behaviourbash
# native build: network is inside the binary
./bin/Fafnir
# no external .nnue file is required

# WASM build: embedding disabled
make -f Makefile.wasm
# compiled with NNUE_EMBEDDING_OFF
i
WASM is differentThe WASM build deliberately disables embedding. A browser artifact carrying a 94 MB network would be impractical; the web edition plan uses a separately served network or a reduced artifact. The public web edition is still in preparation.

Evaluation and units

The probe returns a quantized score that the search consumes directly. For display, the value is normalized to pawn units using NORMALIZE_TO_PAWN_VALUE = 356, matching the convention of Stockfish 17.x. UCI score cp values are centipawns from the side to move.

Score in contexttext
info depth 20 seldepth 34 score cp 35 nodes 553530 nps 464370 time 1192 pv e2e4 ...

A positive cp score favours the side to move. The GUI is responsible for rendering it from White's perspective if that is its convention.

Replacing the network

Replacing the default network is a source-level change, not a runtime option. The file name is referenced by EvalFileDefaultName in the vendored evaluate.h (the single local patch to the snapshot), and the binary embeds whatever file that name resolves to at build time.

i
Architecture compatibilityDo not replace the network with an incompatible architecture. SFNNv17 expects the feature sets and layer layout of the same generation. A mismatched file will fail to load or produce meaningless scores. Rebuild and re-run the EPD suite after any change.

Provenance and license

The network is the default network of the vendored SFNNv17 snapshot and is redistributed under the upstream license. The engine as a whole is GPLv3 because it links GPLv3 Stockfish code. See the license page and third_party/VENDORED.md for the complete breakdown.
