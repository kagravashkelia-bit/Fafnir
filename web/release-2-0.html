Fafnir 2.0

1 November 2026

A consolidation release: the public history was rebuilt, the build system became multi-architecture, the UCI surface was reduced to what actually works, and the website and CI were brought back into the same tree.

Highlights

Four changes define this release.

01

Multi-architecture native builds

One Makefile now produces safe x86-64, SSSE3, SSE4.2, AVX2 and AVX-512 binaries, each in its own object directory. Published archives cover Windows and Linux at three ISA levels.

Build guide
02

A smaller, honest UCI surface

Only Hash, Threads, MultiPV, Move Overhead and Aggressivity are declared. Unknown options answer info string unknown UCI option instead of pretending to work.

UCI reference
03

The network is a normal git blob

The 98,668,604-byte SFNNv17 network is committed directly. Clones and CI embed the real file without an LFS smudge step, and the binary needs no external network.

NNUE details
04

WASM builds again

The workflow had been picking up the JNI bridge and the legacy probe. Both were excluded or removed; the first artifact with the real embedded network was produced on 1 November 2026.

WASM status

Added

  • Native multi-architecture build system in the root Makefile: x86-64 safe default, ssse3, sse4.2, avx2, avx512 and native, with per-architecture object directories and suffix-signed binaries (bin/Fafnir-<arch>).
  • CI workflow build-native.yml: Linux and Windows builds for x86-64, SSE4.2 and AVX2, a UCI smoke test, and packaged artifacts.
  • GPL v3 LICENSE at the repository root and a provenance overview in third_party/VENDORED.md.
  • This documentation site, generated from a single source of truth and deployed to GitHub Pages.

Changed

  • The UCI interface declares only implemented options; unrecognised options answer info string unknown UCI option.
  • Project renamed FlashBit → Fafnir across the repository, website and identity strings.
  • The NNUE network is committed as a plain git blob again (no Git LFS).
  • Makefile.wasm and the CI build are portable across cmd.exe, MSYS2 sh, Linux and macOS shells (idempotent mkdir, no 2>nul).

Removed

  • The unbuildable JNI bridge (src/bridges/java_api.{h,cpp}, integrations/java-jni/): its legacy probe API does not compile against the vendored sfdev snapshot.
  • Long-dead Stockfish probe/ code is no longer referenced by any build. CI no longer mutates the vendored incbin.h; network embedding is disabled for WASM via NNUE_EMBEDDING_OFF.

Fixed

  • build-wasm.yml compiles again. It had been broken since the 31 October source reorganisation pulled in JNI and legacy probe sources.
  • Windows mkdir no longer aborts when the directory already exists during native builds.
Upgrade notes

What changes for you.

Binary name
Published archives use Fafnir.exe on Windows and a Linux binary in the extracted directory.
Network file
Delete any external network path from your GUI configuration; 2.0 embeds the network.
Unknown options
Configuration typos now produce an explicit info string line instead of silence.
JNI users
The Java bridge is gone. Use UCI, or the documented WASM C API when the web edition ships.
History
Tags fafnir2 and 1.3 remain historical markers; their releases were removed.
