Which build?

The instruction set is not a suggestion.

A binary compiled for AVX2 will crash with an illegal instruction on a CPU that does not support AVX2. Choose deliberately, or start safe.

BuildRequiresGood default for
x86-64SSE2 onlyAny x86-64 machine, VMs, unknown hardware
sse4.2SSE4.2 + POPCNTIntel Nehalem (2008) / AMD Bulldozer (2011) and later
avx2AVX2 + BMI2 + POPCNTIntel Haswell (2013) / AMD Excavator (2015) and later
i
AVX-512 is build-it-yourselfThe release does not include an AVX-512 archive. You can build one locally with make ARCH=x86-64-avx512; the benchmark page includes its measured throughput, but it is not a published binary.
⊞

Windows

Unzip the archive and point your GUI at Fafnir.exe. No installer and no DLLs to register.

◉

Linux

Extract with tar -xzf, make the binary executable if needed, and pass its path to the GUI.

Already inside the binary. Do not download a separate .nnue file for these archives.

Release policy

What a release means here.

  • The tag, the source tree and the binaries refer to the same revision.
  • Every asset has a published SHA-256 digest.
  • The engine identity is part of the release: id name Fafnir 2.
  • No asset is rebuilt silently after publication.
  • Earlier tags are historical markers, not supported downloads.

The repository history was consolidated on 1 November 2026. The tags fafnir2 and 1.3 remain reachable, but the releases they once backed were removed. Fafnir 2.0 is the only published release.
