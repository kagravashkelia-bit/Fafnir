Frequently asked questions

Short answers, grouped by the part of the project they concern. If the answer depends on the build, the docs page is linked next to it.

Engine

Is Fafnir a Stockfish fork?

No. Fafnir is a separate engine with its own search, move picker, controller and UCI layer. It uses the Stockfish development SFNNv17 NNUE architecture and vendored evaluation code, which is why the combined work is GPLv3.

How strong is it?

The project does not publish an invented Elo. It publishes its search design, a 100-position EPD regression suite and measured throughput. Strength is a property of game results, not a marketing page.

Does it use an opening book or tablebases?

No. Neither is implemented or declared in 2.0. The GUI or tournament manager can supply a book; Syzygy support is on the roadmap but unscheduled.

Does the engine connect to the internet?

No. It is a local process. There is no telemetry, update check or network request.

Builds

Which archive should I download?

Start with the safe x86-64 build if you are unsure. AVX2 is the right choice for most CPUs from 2013 onward; SSE4.2 covers older machines. A build compiled for an ISA your CPU lacks will crash with an illegal instruction.

Why is the default build slower?

The default target uses SSE2 so the binary runs on any x86-64 CPU. The AVX2 build is about 1.9× faster on the reference benchmark, and AVX-512 about 2.0×.

Can I build with Clang or MSVC?

The Makefile accepts other compilers through CXX=, but CI validates g++ on Linux and Windows. A successful local build with another compiler is not a tested configuration.

The Windows build failed with mkdir. What now?

That bug is fixed in 2.0. Pull the current Makefile, run make clean, and rebuild. The mkdir step is now idempotent.

Can I build for AVX-512?

Yes: make ARCH=x86-64-avx512. The official release does not include an AVX-512 archive, but the build target exists and is benchmarked locally.

Protocol

Which UCI commands are supported?

uci, isready, ucinewgame, position, go, stop, setoption and quit. The full reference lists the accepted go parameters and output fields.

Why are there only five options?

Because only five are implemented: Hash, Threads, MultiPV, Move Overhead and Aggressivity. Declaring a non-functional option breaks GUIs and makes configuration dishonest.

What happens if I set an unknown option?

The engine answers info string unknown UCI option. It does not silently accept the setting.

Does it support MultiPV?

Yes, from 1 to 256 root variations. The multipv field identifies the rank in the info lines.

Does it support pondering?

go ponder is accepted and the engine declares ponder support. ponderhit is not part of the documented command surface in 2.0; check the UCI reference before relying on it.

NNUE

Do I need to download a .nnue file?

No. The native build embeds the network with incbin. The published archives are self-contained with respect to evaluation.

Which network is embedded?

The SFNNv17 default network nn-252f33942263.nnue, 98,668,604 bytes, SHA-256 252f33942263bc8b8f740ba8aec3fed5a159ff148113c47a55c18c33d6627ab3.

Can I replace the network?

Only at build time, and only with a compatible SFNNv17 network. The file name is referenced by EvalFileDefaultName in the vendored evaluate.h. Re-run the EPD suite after any change.

Why is the WASM build different?

WASM is compiled with NNUE_EMBEDDING_OFF because a 94 MB network inside a browser artifact is impractical. The public web edition is still in preparation.

Project

Is there a public WASM build?

Not yet. CI produces a Fafnir-WASM-Build artifact, and the C API is documented, but there is no supported browser release.

Why was the Git history consolidated?

To make the current tree auditable: one snapshot, the real network as a normal blob, no build artifacts, and a documented provenance. Earlier tags remain reachable.

What happened to FlashBit?

It was renamed to Fafnir. The rename covered the repository, website and identity strings; the changelog records it.

Where do I report a bug?

Open a GitHub issue with the OS, CPU, build, exact command or GUI action, and the raw engine output.

Is the website open source?

Yes, it lives in web/ in the same repository and is generated from scripts/build_site.py.
