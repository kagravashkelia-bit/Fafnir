Fafnir 2 — NNUE SFNNv17 — C++17 — Native builds for Windows and Linux.

Evaluation

One network. Every position.

Fafnir embeds the Stockfish dev SFNNv17 architecture and evaluates every leaf node through the nn-252f33942263.nnue network, compiled directly into the binary — no external files to download or configure.

  • Single-output network without PSQT head, inlined at build time
  • Half-KA v2 with horizontal mirroring, plus threats feature sets
  • Quantised accumulator inference across all search threads

Engine

Built as an instrument, not a product.

Layered architecture

A strict three-tier dependency rule: the interface layer never enters the search, and the engine never knows about protocols. Rules, bridges and vendored code remain fully separated.

Optimised natively

Release builds are compiled with -O3, link-time optimisation and explicit instruction-set support: SSE2, SSSE3, POPCNT, BMI1, BMI2 and AVX2.

Validated by regression

A reproducible EPD suite — Bratko‑Kopec, Kaufman, Nolot, LCT‑II and Rybka — guards every change to the search before it is accepted.

Compilation

Terminal
# Safe build (any x86_64 CPU) — output: bin/Fafnir(.exe)
make

# Optimised builds for specific instruction sets
make ARCH=x86-64-sse4.2     # SSE4.2 + POPCNT    (x86-64-v2)
make ARCH=x86-64-avx2      # AVX2 + BMI2 + POPCNT (x86-64-v3)
make ARCH=x86-64-avx512    # AVX-512 + VNNI       (x86-64-v4)
make ARCH=native           # tuned for this machine
make all-arches            # all of the above, suffixed in bin/

# Regression suite (EPD: Bratko-Kopec, Kaufman, Nolot, LCT-II, Rybka)
python tests/tests.py bin/Fafnir.exe --depth 18

UCI commands

CommandDescription
uciNegotiate the protocol. Replies with id name Fafnir 2 and uciok.
isreadySynchronisation handshake; answers readyok.
ucinewgameReset the transposition table and clear all search state.
positionAccepts startpos or a FEN string, optionally followed by a move list.
goSearch control: movetime, depth, wtime/btime, increments and movestogo.
stopInterrupt the running search and emit the best move immediately.

UCI options

OptionRangeDescription
Hash1–1024Transposition table size, in megabytes.
Threads1–128Number of parallel search threads.
MultiPV1–256Number of principal variations reported per search.
Move Overhead0–5000 msSafety margin subtracted from advertised clock time.
Aggressivity0–100Search temperament; higher values favour sharper lines.

Installation note

Point the GUI at bin/Fafnir.exe (Windows) or bin/Fafnir (Linux). Ensure that Threads matches the host machine and that Hash is allocated generously on the transposition-table side.
