Source availability

The complete corresponding source is the public repository at https://github.com/kagravashkelia-bit/Fafnir. The release archives are built from the same tree that contains the engine, the Makefiles, the tests, the vendored dependencies and the network. No binary-only components are required to build or run the engine.

The NNUE network

assets/nnue/nn-252f33942263.nnue is the default network of the vendored SFNNv17 snapshot. It is redistributed under the upstream license. Its SHA-256 is:

Network SHA-256text
252f33942263bc8b8f740ba8aec3fed5a159ff148113c47a55c18c33d6627ab3

Local patch to vendored code

There is one documented local patch: third_party/stockfish/sfdev/src/evaluate.h changes EvalFileDefaultName to point at assets/nnue/nn-252f33942263.nnue. The patch is recorded in third_party/VENDORED.md. The legacy third_party/stockfish/probe/ directory is present for provenance but is not compiled into any binary.
