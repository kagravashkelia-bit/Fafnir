Project

A dragon, a pawn, and a lot of search output.

Fafnir is an independent UCI chess engine written in C++17. It is not a Stockfish fork with a new name: the search, move picker, controller and protocol layer live in this repository. The evaluation uses the Stockfish development SFNNv17 architecture, which is why the whole project is GPLv3.

Origin

From FlashBit to Fafnir.

The engine was previously published as FlashBit. The rename was not cosmetic: it came with a new identity chain, a rebuilt public history, a multi-architecture build system and a documentation site that matches the binary.

On 1 November 2026 the public history was consolidated into a single descriptive snapshot. The goal was not to erase the past but to make the current tree auditable: one commit, 127 files, the real 98,668,604-byte network as a normal Git blob, and no build artifacts or leftover scripts. Earlier revisions remain reachable through the fafnir2 and 1.3 tags.

i
What “independent” means hereFafnir does not claim to be stronger than any other engine, and it does not publish invented Elo. It publishes its search design, its build flags, its test suite and its measured throughput. Strength claims belong to game results, not to a marketing page.

Principles

Four rules the project actually follows.

01

Ship it or omit it

No placeholder UCI options, no disabled menu entries, no “coming soon” in the protocol. If it does not work, it is not declared.

02

Measure it or qualify it

Performance numbers include the machine and the protocol. Strength is not inferred from NPS.

03

Document the removal

Dropped interfaces are recorded in the changelog. Silent deletion is a bug in the documentation.

04

Keep the binary portable

The default build is safe on any x86-64 CPU. Faster builds are opt-in and clearly labelled.

The name

Fafnir.

In Norse myth, Fafnir is a dragon guarding a hoard. The logo keeps the dragon and adds a pawn: the hoard is a chess position, and the engine is the thing that refuses to give it up.

The mark is deliberately monochrome with a small blue circuit accent. It is the only brand flourish on the site; the interface stays white, black and light gray.

The Fafnir mark, derived from the project logo.

Credits

Standing on documented shoulders.

ChessLib provides the board representation. The Stockfish development snapshot provides the NNUE implementation. incbin makes the network portable. The mistakes are ours.

A

Anthony

Engine author, maintainer and the person behind the Fafnir identity. Responsible for the search, protocol layer and build system.

C

Disservin / ChessLib

A fast, header-only chess library used for board state, move generation and FEN/UCI helpers. MIT licensed.

S

Stockfish contributors

The SFNNv17 evaluation architecture, NNUE feature sets and the reference search style that informed this implementation. GPLv3.
