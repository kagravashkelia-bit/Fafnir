# Fafnir

**Fafnir** is a free, open-source UCI chess engine written in C++17. It is the
continuation of the FlashBit project.

Fafnir uses an NNUE evaluation built on the Stockfish SFNNv17 architecture and
follows the Stockfish search design: iterative deepening PVS with a transposition
table, late move reductions, null move pruning with verification, singular
extensions and multicut, ProbCut, aspiration windows, SEE-based move ordering,
cuckoo-based repetition detection, correction history and more.

The NNUE network is embedded in the executable, so there are no external files
to install: the engine is a single self-contained binary.

## About this project (an LLM experiment)

100% of the source code in this repository was written by large language models,
under human direction and testing. The project is also an experiment: how good can
a complete chess engine be when the code is generated by current LLMs?

For that reason the engine is published openly so that its strength can be measured
by independent, automated testing (rating lists and engine tournaments) instead of
self-reported numbers.

## Features

- Full UCI protocol, standard chess
- NNUE evaluation (SFNNv17), network embedded in the binary
- Multi-threaded search (SMP) and MultiPV
- Pondering
- Syzygy tablebase probing
- Optional Polyglot opening book (`OwnBook`, `Book File`)
- Adjustable hash, move overhead and a playing-style option (`Aggressivity`)
- Portable x86-64 builds: AVX2, SSE4.1+POPCNT, or baseline SSE2
- No external runtime dependencies on Windows (the MinGW runtime is linked statically)

## Download

Pre-built Windows binaries are on the [Releases](../../releases) page. For most
64-bit systems use the **AVX2** build.

The engine is self-contained; no DLLs, networks or book files are required.

## UCI options

| Option        | Type   | Default | Range / notes                            |
|---------------|--------|---------|------------------------------------------|
| `Hash`        | spin   | 256     | 1 - 1024 MB                              |
| `Threads`     | spin   | 1       | 1 - 128                                  |
| `MultiPV`     | spin   | 1       | 1 - 256                                  |
| `SyzygyPath`  | string | empty   | Path to Syzygy tablebases                |
| `OwnBook`     | check  | false   | Enable the Polyglot book                 |
| `Book File`   | string | empty   | Polyglot `.bin` book                     |
| `Move Overhead` | spin | 50      | Milliseconds reserved for GUI/network    |
| `Aggressivity`  | spin | 0       | 0 - 100, shifts the evaluation optimism  |

## Building from source

Requirements:

- A C++17 compiler (GCC 11+ or Clang 12+; MinGW-w64 is used for the Windows builds)
- `make`
- `nn-252f33942263.nnue` in the repository root (it is included in the repository
  and embedded into the executable at build time)

Build for the machine you are compiling on:

```sh
make -j
```

Build a portable binary for distribution:

```sh
make clean
make -j ARCH=x86-64-avx2
```

Available `ARCH` profiles:

| `ARCH`                  | Target                                              |
|-------------------------|-----------------------------------------------------|
| `native` (default)      | Tuned for the build machine                         |
| `x86-64-avx2`           | Intel Haswell / AMD Zen or newer (recommended)      |
| `x86-64-sse41-popcnt`   | Older 64-bit CPUs without AVX2                      |
| `x86-64`                | Baseline x86-64 (SSE2 only)                         |

Run `make clean` when switching between profiles, since object files are reused.

The executable is called `Fafnir.exe` on Windows and `Fafnir` elsewhere.

## Testing

`tests/tests.py` runs a 100-position best-move regression suite against a UCI
engine:

```sh
python tests/tests.py ./Fafnir.exe --depth 18
```
