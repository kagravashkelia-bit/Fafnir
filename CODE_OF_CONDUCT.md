# Code of Conduct

Fafnir is a small hobby-maintained chess engine; contributor behaviour still
matters. In this repository and its discussion channels:

- Be accurate. Do not claim behaviour, benchmarks or features that have not
  been demonstrated; the project's own documentation is held to the same
  standard.
- Be respectful in code review: discuss the change, not the person.
- The vendored code in `third_party/` is distributed under its own licences
  (GPLv3, MIT, Unlicense) — respect their attribution when reusing it.

Violations may be reported through a private GitHub security advisory or a
direct message to the author. Maintainers may remove comments or revoke
participation privileges.

This is a plain-text policy consistent in spirit with the Contributor
Covenant; no template boilerplate is imposed on contributors.
